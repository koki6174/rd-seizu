# 見えない病気の星図

参加者の「伝えたい」「知りたい」を光として蓄積する、参加型の展示サイトです。

## ページ
- `/` — 公開準備中
- `/admin/` — 参加型星図（一般参加者向け。管理者専用画面ではありません）
- `/weekly/` — 累積の星図レポート
- `/privacy/` — プライバシーポリシー

## 構成
GitHub Pagesの静的ページとSupabaseを使用します。匿名参加、疾患名検索、コメントの承認待ち、週次集計に対応しています。病名の追加申請は運営の確認後に反映します。

公開用の設定は `config.js` に配置します。秘密鍵を公開コードに含めないでください。データベースの読み書きはRLSと必要なRPCで制御しています。

## データの出典
疾患名の日本語表記には厚生労働省「指定難病一覧」、NANDO/DBCLSおよび [136s/intractable-disease](https://github.com/136s/intractable-disease) の公開データを参照しています。公開データのライセンス表示と更新履歴は [data/README.md](data/README.md) を参照してください。

表示する疾患の同一性・表記ゆれは継続して確認します。診断や治療について助言するサービスではありません。
