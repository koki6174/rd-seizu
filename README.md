# 見えない病気の星図

参加者の「伝えたい」「知りたい」を光として蓄積する、参加型の展示サイトです。

## ページ
- `/` — **メイン**：1,241疾患の分類ベース3D星図と、一般参加者向けの星を灯すフォーム
- `/clinical/` — 医学的特徴量（HPO・遺伝子）に基づく**研究用の別ページ**。現在144件。メイン星図とは独立
- `/admin/` — 旧参加URL。メインの参加フォームへ自動移動
- `/lab/` — 旧立体星図URL。メインの3D星図へ自動移動
- `/weekly/` — 累積の星図レポート
- `/privacy/` — プライバシーポリシー

## 構成
GitHub Pagesの静的ページとSupabaseを使用します。匿名参加、疾患名検索、コメントの承認待ち、週次集計に対応しています。病名の追加申請は運営の確認後に反映します。

公開用の設定は `config.js` に配置します。秘密鍵を公開コードに含めないでください。データベースの読み書きはRLSと必要なRPCで制御しています。

## データの出典
疾患名の日本語表記には厚生労働省「指定難病一覧」、NANDO/DBCLSおよび [136s/intractable-disease](https://github.com/136s/intractable-disease) の公開データを参照しています。公開データのライセンス表示と更新履歴は [data/README.md](data/README.md) を参照してください。

表示する疾患の同一性・表記ゆれは継続して確認します。診断や治療について助言するサービスではありません。

## 星図の区別

メインの1,241件はNANDO等の分類から数値化した34次元特徴量をPCA/FCMで配置したものです。これを医学的な症状の類似性による星図と誤解しないようにしてください。

別ページ `/clinical/` の144件はOrphadata由来の陽性HPO、原因遺伝子、遺伝形式、発症時期に基づく研究用UMAP/FCMの配置です。こちらは第三者による医学的な距離の検証が未完了です。メインページは医療用の座標を取得しません。

参加機能・星の明滅は両ページとも同じ公開投稿データを参照しますが、星への参加操作と疾患検索はメインページで行います。
