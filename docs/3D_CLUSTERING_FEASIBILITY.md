# 3D医療関連星図：実現性評価と実データによる試作（2026-10-10）

## 判定

**技術的に実現可能。現時点では分類情報のみのPCA＋FCM実証モデルを作成した。**
本サイトをいきなり置換せず、スマホ・PCで比較できる `/lab/` を独立した試作ページとして公開する。

試作：`https://koki6174.github.io/rd-seizu/lab/`

- 1,241疾患・疾患群・病型に固定3D座標を作成した。
- **未投稿の星も消さず、暗い点として表示**。投稿件数が1以上の疾患は色と光量を付けて表示。
- タップした星の名前・累積件数・承認済みコメントを表示。指で回転・ピンチズーム可能。
- 本番の `/admin/`、Coming Soonの `/`、`/weekly/` に変更しない。
- 現時点で星の座標は「臓器系分類と階層」による。**3D上の距離が疾患の遺伝学・症状・病因の近さを測っているわけではない**。視覚調整のためクラスタ間に反発処理を行っている。

### 初期34次元の構成

- NANDOの大分類と小児慢性側のカテゴリーを照合して作成した**17種類の広域分類**をOne-hot化（16分野＋未分類）。
- 原典の小児慢性の16カテゴリーを別ブロックでOne-hot化。
- サブタイプかどうかの構造的フラグを追加。
- `34`次元（`17 + 16 + 1`）。強度は大分類2、小児分野0.45、サブタイプ0.4で固定した初期試験値。**この重みは医学的妥当性を検証していない**。
- PCAで3成分に射影。寄与率：**23.32%、16.43%、8.88%（累計約48.63%）**。
- 高次元の同じ特徴量に**FCM：13クラス、m=2** を適用（実測8回の更新）。
- その後、表示上の重なり回避・親子疾患の近接・端末での見やすさのため、決定的な微小位置調整および分野中心の反発処理。位置は毎回同じ。
- **FCMはクラスタリングの演算テストであり、疾患の医学的分類精度の検証ではない**。カテゴリーのみを入力したため、既知の分類を再構築する結果は自明である。

### 出典の公開条件

- [NANDO/DBCLS](https://github.com/NanbyoData/nando) はCC BY 4.0。疾患データは旧版由来であり、現行年度差分は未反映。
- [MONDO](https://mondo.monarchinitiative.org/) は相互運用性のための厳密な同等性マッピングと疾患階層を提供。CC BY 4.0。
- [Orphadata Science](https://sciences.orphadata.com/orphanet-scientific-knowledge-files/) 2026年版には疾患症状、原因遺伝子、疫学、外部分類との照合データがありCC BY 4.0。日本語名とORPHAcodeの**確実な対応付けが前提**。
- [HPO](https://obophenotype.github.io/human-phenotype-ontology/annotations/introduction/) の `phenotype.hpoa` は疾患×症状の頻度、発症時期などを表現できる。ただしOMIM由来等の注釈に再利用条件があるため確認する。

## 次の本格モデル：ファクトと欠損を分離する

### データ取り込みの順番

1. **疾患概念の同一性**：MONDOとORPHAcode、同義語、親子関係。広い「疾患群」と狭い「病型」の単純統合は禁止。
2. **症状・臓器系**：HPOアノテーションの陽性・否定・頻度・根拠。未収載は陰性ではない。
3. **遺伝と病因**：既知の原因遺伝子、遺伝形式（AD/AR/X連鎖/ミトコンドリア/非遺伝性等）、研究文献。
4. **発症時期と疫学**：発症年齢、患者数ではなく人口ベースの有病率、地域と調査年、方法、信頼区間、数値化不能な幅。欠損マスクを設ける。
5. **治療開発**：国内承認薬・臨床試験・支持療法を別々の変数にし、`治る/治らない`の単一ラベルを避ける。
6. **生存率**：意図的に除外。

### 特徴量化・検証

- 数値量は `log1p`やロバスト標準化の適否を検証。カテゴリはmulti-hot。HPOでは陽性、明示的陰性、未調査を区別。
- 欠損割合を疾患ごとに表示する（モデル内部）。出典・地域・評価年を保持。
- PCAと3D UMAPを比較し、FCMだけでなくHDBSCANなども検討。
- 臓器系だけで固まる自明なモデルを避け、HPOや遺伝関連の実測情報を優先して評価。
- 再計算で位置が全く異ならないよう、seed・版管理と既存地図へのProcrustes整合を検討。
- 近傍保存率、trustworthiness、親子近接性、クラスター安定性、出典被覆率を評価。**3D距離を臨床判断に用いない**。
