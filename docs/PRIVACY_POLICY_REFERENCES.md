# プライバシーポリシー作成時の参照資料（2026-10-10）

公開URL：`/privacy/`。公開ページには法律解説や技術上の細部を長く列挙せず、実際に取得する情報・利用目的・公開ルール・選択肢を短く記載。

## 参照した資料
1. 個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン（通則編）」
   https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/
   - 法21条：取得する個人情報の利用目的の通知・公表、入力画面で目的を確認できる配置。
   - 法32条：該当する「保有個人データ」の公表・請求対応、事業者の名称・住所等。
2. 個人情報保護委員会「個人関連情報とは何か」
   https://www.ppc.go.jp/all_faq_index/faq2-q2-8/
   - 閲覧履歴等も個人関連情報に該当し得る。「個人特定できない」ことだけを理由に説明を省くのは適切でない。
3. デイライト法律事務所「プライバシーポリシーとは？必要性や記載例を解説｜ひな形付」
   https://www.komon-lawyer.jp/qa/privacy/
   - 実際の事業内容に応じ、利用目的を具体化し、ひな形をそのまま使わないことを確認。
4. e-Gov「個人情報の保護に関する法律」第21条、第32条
   https://laws.e-gov.go.jp/law/415AC0000000057

## 現サイトのコードと整合させた点
- `star_entries`：参加日・選択病名・投稿種別・ブラウザ識別ハッシュ・コメント。
- `disease_suggestions`：病名の追加申請は非公開・審査対象。
- `exhibition_analytics`：画面・操作経路・滞在秒数。任意計測の停止は`nenone-analytics-optout`を参照。
- 定型文は事前に定められた文章のため即時表示。自由記述は承認後に公開。
- 集計などの保存先はSupabase。本人確認済みのデータが含まれるとは限らないが、病気に関するテキストは慎重に扱う。
- `/privacy/`の停止ボタンを残し、`/`、`/admin/`、`/weekly/`から統一された「プライバシーポリシー」へリンクする。

## 展示前の運営確認事項
- **実際の運営責任主体（氏名・団体名）と、Webからも使える問い合わせ窓口**を確定すること。現在の「展示の運営担当者」は展示会場内での案内であり、保有個人データがあれば法32条で必要になる事項を十分に満たすとは限らない。
- 保有個人データに該当する場合の開示等手続、事業者住所・安全管理措置等の本人への提供方法を検討すること。
- 自由記述に本人の病歴等の要配慮個人情報が含まれる場合、取得方法・事前同意の要否・モデレーションを別途点検すること。
- 行動計測データの保存期間や削除運用は、運営側で実装・継続確認すること。現在は確実な自動削除が設定されていないため、公開ページでは90日間の自動削除を約束しない。

法的な適合性を保証する文書ではなく、今後の運営確認と参照先の記録。
