# さらに100件追加した疾患別の詳細解説（2026年10月12日）

## 現状と対象

2026年10月12日のGitHub mainに掲載されていた**453疾患**を実際に読み込み、既存IDの一意性を確認した上で、重複しない100疾患を選定しました。公開予定の解説は合計**553疾患**、疾患カタログ全体1,241件に対して44.6%です。

新規100疾患の3本文は合計**17414文字**（JavaScriptのUnicodeコードユニット数。見出し・氏名・出典情報除外）。全件に「どんな病気？」「暮らしとの関係」「医療と研究の現在地」があります。

選定理由は、単なる大分類の「指定難病」に限定せず、現行の星図で別々の星として存在する具体的な疾患・病型を説明するためです。DuchenneとBeckerの筋ジストロフィー、CMTの脱髄・軸索型、SMAのI〜IV型、神経免疫疾患、先天代謝異常などの相違を文章に反映しました。

## 原典の対応と医学的検証の範囲（重要）

公開用JSONの`sourceScope`は**参照資料の対応付け強度**であり、医学専門家の独立した文章監修を意味しません。

- **32件：`exact_orphanet_crosswalk`**。研究用の`disease_orpha_mappings`で確認された個別ORPHAcodeと陽性HPO症状を持つ疾患。対応するOrphanet疾患別詳細ページと症状一覧の2リンクを保存した。厳密な医学的同一性に関する外部監修を受けたわけではありません。
- **47件：`official_parent_disease_explanation`**。難病情報センターの公式解説に、当該病型を含む大分類・病型群の説明があるもの。必ずしも**病型別の詳細説明を一段落ずつ確認したわけではない**点に注意。
- **21件：`official_disease_group_index`**。難病情報センターの公式索引と厚生労働省の指定難病資料を参照。**個別の病型の原典まで精査できていない編集草稿**であり、追加の原典チェックを優先する。

すべての記述は、治療適応・薬剤選択を一律に推奨するものではありません。生存率・余命・薬剤用量を載せず、患者さんによる個人差や病型間の違いに配慮しました。**自動テストで医学的正確性の全保証はできない**ため、専門的な再確認を経て段階的な修正を推奨します。
