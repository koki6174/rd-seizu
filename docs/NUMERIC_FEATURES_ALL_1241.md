# 1,241件すべての数値特徴量DB（2026-10-11）

## 結果と科学的な線引き

全**1,241件の疾患・疾患群・病型**に、**34次元の分類数値特徴量**を持つプライベートDBを作成した。疾患の実測HPO、遺伝子、遺伝形式、発症時期の情報は、それぞれ**観測できた場合だけスパース数値特徴量**として別途追加した。**記載なしはゼロや臨床的な陰性とみなさずNULL**を保持する。

| 取り込めたもの | 対象レコード |
| --- | ---: |
| 数値特徴量のレコード | **1,241 / 1,241** |
| 34次元の数値化（未知分類の専用次元を含む） | **1,241 / 1,241** |
| 根拠のあるNANDOまたは小児慢性分類 | **1,225** |
| 疾患分類未整備（未知分類コードのまま） | **16** |
| 疾患・下位病型のNANDO ID階層（1以上） | **655** |
| HPOの陽性症状注釈あり | **144** |
| 疾患原因関連遺伝子あり | **96** |
| 遺伝形式の原典注釈あり | **118** |
| 発症時期の原典注釈あり | **144** |
| 確認済みの研究用ORPHA紐付け | **144** |
| 疾患とHPO症状の関連レコード | **5,391** |

**重要：医学的な症状・遺伝子で全1,241件をクラスタリングできた、という意味ではない。** 現在の医学的特徴量の実データは144件である。残る1,097件は臨床注釈不足なので、病態について埋めるべき未知情報が残る。カテゴリ分類による36/37次元相当の構造特徴と臨床所見を混同しない。

## DBの設計

`public.disease_numeric_feature_profiles`（RLSで匿名・通常ユーザーから読み取り不可）：

- `taxonomy_vector`：すべての1,241概念で**34個の数値**（17分類、16小児群、1病型フラグ）。元の2016-2026 NANDO分類の性質を保持するため、旧試作の重みを維持。値は医学上の重症度・治療効果を示さない。
- `taxonomy_group_code`、`taxonomy_parent_depth`、`nando_id_subtype_depth`、`n_children`：疾患の階層を客観的に数値化。最後の2件は**歴史的NANDOの識別子の構造に関する特徴**。
- `hpo_sparse_weights`：**肯定的に注釈されたHP用語のみ**が入るJSONB疎ベクトル。頻度記述（Obligate 1.0、Very frequent .90、Frequent .60、Occasional .25、Very rare .07、注釈済みで頻度不詳 .35）の値を保持。
- `causal_gene_sparse`：Orphadataの`Disease-causing`関連のみ。リスク上昇（susceptibility）や修飾遺伝子は原因としない。
- `inheritance_observed`、`onset_observed`：出典にあるカテゴリーだけを数値化。
- `observed_mask`：分類・症状・原因遺伝子・遺伝形式・発症時期それぞれの観測有無。**マスクがfalseでも「その症状がない」とは意味しない**。
- `medical_identity_evidence`：過去の照合、親疾患の照合、MONDO・NANDO・Orphanetの三者照合などのエビデンスレベル。いずれも外部臨床審査の完了を表さない。
- `feature_version`：データ取得・再計算時の版管理。

`public.refresh_disease_numeric_profiles()`：照合・医学的エビデンスが増えた時に上記の特徴量と観測マスクを再計算。通常の訪問者から実行不可。

`supabase/migrations/036`～`043`、実施した初期源クラス修正4件とともに再現できる。候補が本番の公開モデルに自動混入する仕組みではない。

### 医学的な信頼性に関する設計原則

- **分類ベクトルが1,241件すべてに存在する**ことと、**症状/遺伝形式/原因遺伝子が実測済み**であることを必ず区別する。
- 患者数・希少性・治療薬承認・有病率の根拠が無い項目は補完しない。受給者証所持者数は有病率ではなく、今回の臨床ベクトルに利用していない。
- 広い疾患群と個別病型は無条件に同じ概念として扱わない。
- 原因遺伝子なし/症状の注釈なしを生物学的な陰性と誤解させない。
- 患者投稿・コメント・ブラウザ識別子・管理上のランダム紹介基準は特徴量計算に使わない。

## 公式照合ソースから、新規75候補を探索

全1,241件のうち英語名を持つ852件を、以下の公式情報で横断的に照合した。

1. MONDO 2026-10-06：NANDOへの手動`hasDbXref`。
2. MONDO 2026-10-06：Orphanetへの`skos:exactMatch`。
3. 元のNANDO病名、MONDO優先病名、Orphanet優先病名の厳密一致。
4. ORPHAcodeが他の国内IDと重複しないこと、広い小児疾患群を自動マージしないこと。
5. ORPHApacketの実体ファイルでORPHAcode・名称・疾患概念の種類・陽性HPOの存在を再検査。

**新たに75件の独立した照合候補**を検出して、DBの非公開 `disease_mondo_orpha_review_queue` と `disease_orpha_evidence_staging` に保存。

| 照合候補の状態 | 件数 |
| --- | ---: |
| 新しいORPHA候補 | 75 |
| そのうちHPO注釈あり | 33 |
| ORPHAの種類とNANDOの病型の両方が一致し、HPO陽性注釈がある研究用追加 | **24** |
| 残る研究候補（疾患群などの粒度要確認・HPO未注釈） | **51** |
| 前段階からの別の未確認候補 | **19** |

追加24件は、同じ`Clinical subtype`の概念粒度に絞り、MONDO/NANDO/Orphanetの優先英語名を厳密に突き合わせた研究用の出典検証。**臨床医による個別審査ではない**。さらに慎重なレビューを行うなら、一般来場者の医学的解釈に使う前に必要。

## 3D研究星図：120→144疾患

追加24件（HPO関連904件）を登録し、PCA・3D UMAP・FCMを再学習した。

| 比較 | PCA | UMAP |
| --- | ---: | ---: |
| 研究用の疾患数 | 144 | 144 |
| 入力次元数 | 2,281 | 2,281 |
| Trustworthiness | 0.8377 | **0.9150** |
| k近傍保存率（k=7） | 0.2728 | **0.5347** |
| FCMシルエット | 0.3521 | **0.3936** |
| UMAP seed整合安定性 | - | **0.9490** |

入力は**HPO症状2,065語彙、原因関連遺伝子200語彙、遺伝形式8分類、発症時期8分類**。FCMは3D射影後の5クラスター。これらの内部指標は疾患概念や医学的治療の判断を正当化しない。

`public.disease_clinical_embedding_pilot` と公開用研究APIには**144件**の研究用座標を登録した。
`public.disease_embedding_coordinates`の分類星図は**1,241件そのまま**。

> 見た目の星団位置は統計的な配置であり、病名同士の医学的診断距離ではない。

### 今後の優先順位

全1,241件について医学的特徴量を増やすには、まず日本語名しかない**389件**と、医学的概念の粒度が異なる疾患群の外部識別子を照合する必要がある。特にNANDO最新オントロジー、MONDO、ORPHAcode、HPOを繋ぐ同等性の根拠が必要。出典のない遺伝/発症情報は生成モデルで補完しない。

**未調査と陰性の明確な区別は保持したまま、医学的な実データのカバレッジを拡大する**。第三者の医学専門家による定義・概念粒度の確認が最終品質のボトルネックとなる。
