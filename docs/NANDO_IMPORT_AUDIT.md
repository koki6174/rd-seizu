### 二重登録を防ぐ処理

- 日本語病名をUnicode NFKC・空白・記号などで正規化し、既存病名と照合。元データにある英語名が完全一致する場合も統合の補助に使用。
- 既存の指定難病は**IDを変更せず**、ソースの名称・コードを内部対応表 `disease_external_mappings` に保存。
- 原資料内にも複数回出てくる「Danon病」「サラ病」「ネザートン症候群」「チェディアック・東症候群」は別々の星を作らず同じIDへ紐づけ。
- 一部の元データの「〇〇（Ⅰ型）」のような**病型・サブタイプ**は、疾患群と同じ病名ではありません。親子関係 `parent_disease_id` を保存して、検索画面では「関連する分類」を表示します。
- **単純な編集距離や、括弧内を削除した名称一致を理由に疾患を統合しません。** 例えば「ウォルマン病」と「ウィルソン病」は字面が似ていますが別疾患です。

### 英語・略称から日本語での表示へ

18のソース項目が日本語では略号表記のみでした。NANDOに日本語の別名があるものはそれを採用し、不足分は医療情報ソースを参照して日本語表記を付与しました。
**公開用の`name_ja`には日本語表記を使用**し、元の略号や英語表記は検索キーワードとして保持します。

例：
- MSA-C → **多系統萎縮症（小脳型・MSA-C）**
- MSA-P → **多系統萎縮症（パーキンソン型・MSA-P）**
- NSIP → **非特異的間質性肺炎**（NANDO同義語）
- cblA → **メチルマロン酸血症（cblA型）**
- NBIA1 → **パントテン酸キナーゼ関連神経変性症（NBIA1）**

「IBID」の表示ラベルは仮の説明的な日本語表現を用いているため、専門確認を推奨します。
医療情報の説明・治療・疫学値・生存率はここから自動的に転記していません。

### 表記の似ている疾患・別名の「保留」

検出された**共有別名11グループ**には以下の例があります。

- **ムコ多糖症Ⅰ型**：複数のHurler/Scheie病型が同じ上位名称で検索される場合がある（必ずしも同一ではない）。
- **dyskeratosis congenita**：日本語名「先天性角化異常症」「先天性角化不全症」に同じ英語名が付与されている。概念重複の可能性があり、専門チェック推奨。
- **glycogen debranching enzyme deficiency**：複数の酵素欠損サブタイプで同じ英語別名が使われる。
- **autosomal dominant spinocerebellar degeneration** が劣性疾患に誤付与されていたため、**劣性側の英語名を修正**。
- **type II biliary atresia** がⅠ型にも付いていたため、**Ⅰ型の英語名を修正**。

共有別名は、それだけで確実な重複とは断定できません。
**0組という数字は正規化後の表示病名の完全重複だけの結果です。医学的に等価な全表記を完全に排除できたという意味ではありません。**
今後、NANDOの新しいIDとORPHAcode/MONDOで段階的に関係を照合します。
