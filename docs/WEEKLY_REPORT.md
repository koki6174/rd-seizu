# 今週の星図：Web閲覧・A4印刷

公開先（GitHub Pages）： https://koki6174.github.io/rd-seizu/weekly/

- トップ `/` は Coming Soon のままです。
- 展示アプリ `/admin/` とは別のページです。現在の `/admin/` に認証はありません。
- 表示中の週は月曜00:00〜翌月曜00:00（日本時間、終了時刻を含まない）です。
- `/weekly/?week=2026-10-05` のように月曜日の日付を指定すると、その週を表示します。
- 前の週・次の週を画面上で切り替え、［印刷 / PDF保存］でA4縦のレポートを出力できます。
- ダークデザインで印刷する場合、ブラウザの印刷設定で「背景のグラフィック」を有効にしてください。
- **月〜日の1週間が確定したデータを印刷したい場合は翌週の月曜以降に「前の週」を選択してください。**

## 集計内容

Supabase RPC `get_weekly_constellation(p_week_start)` によりリアルタイムの集計結果を取得します。

- 「関心の記録数」：関心ボタン操作のイベント件数。**参加人数ではありません**。同じ人が複数回押した場合もそれぞれ計上します。
- 「注目された星」：その週で最多の関心操作があった疾患（同率の場合は疾患ID昇順）。
- 「今週の問い」：運営が確認・承認した文章のみ。
- 「星図の成長」：先週と今週のイベント件数の変化（ただし両週とも進行中／確定済みの区別は利用者が選択した週に依存します）。
- 「7日間の関心」：日本時間に基づく曜日別のイベント件数。
- データの取得・印刷時点の数値であり、週の途中で印刷すると後から数値が増えることがあります。

## 「今週の問い」を掲載する（編集者向け）

Supabase Dashboard → Table Editor → `public.weekly_editorial` で週ごとに行を作成します。

| 列 | 設定例 |
| --- | --- |
| `week_start` | `2026-10-05` （必ず月曜日） |
| `featured_question` | 運営が内容を確認して公開可能と判断した問い |
| `growth_note` | 必要なら成長欄の補足文 |
| `approved` | 内容を確認してから `true` |

`approved=false` は公開ページに表示されません。承認した行も匿名ユーザーは読み取り専用です。

**自由記述の生データ `public.questions` は自動的に公開しません。**
個人情報・健康情報・誹謗中傷・不適切な内容がないか確認し、必要なら要約・言い換えを行ってから掲載してください。
掲載の承認／編集はDB Dashboardまたは管理権限のあるサーバー側で行います。公開JavaScriptにservice_role key / secret keyを置かないでください。

## データ保全

- 既存の `interactions` と `questions` の行は、この機能の追加で削除・初期化されません。
- `__` で始まる人工的なテスト疾患IDは週次集計から除外しますが、DBには残しています。
- 既存データへの週別集計は後から選択し直せます。現時点では定期スナップショットや自動メール配送はありません。
- Supabase Freeのプロジェクト停止やデータ事故への備えとして、別途定期バックアップを推奨します。
